    实例化

    LearnOpenGl 计算机图形学 OpenGl
    发布时间 : 2026-08-14 15:52
    字数:1.1k 阅读 :
    1. 实例化数组
      1. 1. 顶点着色器修改
      2. 2. 配置实例化顶点属性
      3. 3. 渲染循环提交绘制

    当要绘制大量重复模型时，比如绘制大量的草，不同模型在场景里的区别是是世界空间变换不同（位置、缩放、旋转）。
    这个时候每绘制一个草，都把草模型的顶点数据发送给GPU，就会造成大量性能浪费，每次发送顶点数据时多余的开销。
    这个时候其实只要给GPU一份草模型的顶点数据，以及不同草的在世界空间的变换（model矩阵）就行。这就是实例化的思想。

    在OpenGL中用普通的绘制，绘制大量相同物体时大致是这样的。

    for(unsigned int i = 0; i < amount_of_models_to_draw; i++)
{
    DoSomePreparations(); // 绑定VAO，绑定纹理，设置uniform等
    glDrawArrays(GL_TRIANGLES, 0, amount_of_vertices);
}

    通过glDrawArrays或glDrawElements来提交顶点数据

    在OpenGL中使用实例化，我们只需要将原本的绘制函数改为对应的实例化版本：glDrawArraysInstanced 或 glDrawElementsInstanced。

    这些实例化绘制函数相比普通的绘制函数多了一个参数：实例数量。它直接告诉GPU需要一次性绘制多少个相同的模型。

    实例化数组

    为了让每个实例在世界空间中有不同的位置、缩放和旋转，我们需要将每个实例的变换矩阵传递给着色器。当实例数量非常大（如100000个）时，使用 uniform 传递数据会超出最大限制。此时最有效的方案是使用顶点属性（Vertex Attributes）。

    1. 顶点着色器修改

    在顶点着色器中，我们新增一个 mat4 类型的顶点属性 instanceMatrix。用它替代原本的 model uniform 矩阵来计算顶点位置：

    #version 330 core
layout (location = 0) in vec3 aPos;
layout (location = 1) in vec3 aNorm;
layout (location = 2) in vec2 aUVs;
layout (location = 3) in mat4 instanceMatrix; // 实例化变换矩阵

uniform mat4 view;
uniform mat4 projection;

out vec3 Normal;
out vec2 TexCoords;

void main()
{
    // 使用 instanceMatrix 进行模型变换
    gl_Position = projection * view * instanceMatrix * vec4(aPos, 1.0);
    Normal = aNorm;
    TexCoords = aUVs;
}

    片段着色器则保持正常的光照或纹理采样逻辑，无需为实例化做额外修改。

    2. 配置实例化顶点属性

    在C++代码中，配置 mat4 的顶点属性比普通的 vec3 更复杂。因为顶点属性允许的最大数据量等同于一个 vec4，而一个 mat4 包含4个 vec4，所以我们需要为它保留4个连续的顶点属性位置。

    首先，生成矩阵数据并存入新的VBO中：

    unsigned int modelBuffer;
glGenBuffers(1, &modelBuffer);
glBindBuffer(GL_ARRAY_BUFFER, modelBuffer);
glBufferData(GL_ARRAY_BUFFER, rockAmount * sizeof(glm::mat4), &rockModels[0], GL_STATIC_DRAW);

    接着，在绑定模型的VAO后，配置这4个连续的属性指针（location 3, 4, 5, 6）。最核心的步骤是调用 glVertexAttribDivisor：

    for (unsigned int i = 0; i < rockModel.meshes.size(); i++)
{
    unsigned int VAO = rockModel.meshes[i].GetVAO();
    glBindVertexArray(VAO);
    
    // 顶点属性 3
    glEnableVertexAttribArray(3);
    glVertexAttribPointer(3, 4, GL_FLOAT, GL_FALSE, sizeof(glm::mat4), (void*)0);
    // 顶点属性 4
    glEnableVertexAttribArray(4);
    glVertexAttribPointer(4, 4, GL_FLOAT, GL_FALSE, sizeof(glm::mat4), (void*)(1 * sizeof(glm::vec4)));
    // 顶点属性 5
    glEnableVertexAttribArray(5);
    glVertexAttribPointer(5, 4, GL_FLOAT, GL_FALSE, sizeof(glm::mat4), (void*)(2 * sizeof(glm::vec4)));
    // 顶点属性 6
    glEnableVertexAttribArray(6);
    glVertexAttribPointer(6, 4, GL_FLOAT, GL_FALSE, sizeof(glm::mat4), (void*)(3 * sizeof(glm::vec4)));

    // 告诉OpenGL这些属性是实例化属性，每绘制一个实例更新一次
    glVertexAttribDivisor(3, 1);
    glVertexAttribDivisor(4, 1);
    glVertexAttribDivisor(5, 1);
    glVertexAttribDivisor(6, 1);
    
    glBindVertexArray(0);
}

    glVertexAttribDivisor 函数改变了顶点属性推进的方式。默认情况下参数为0，表示每绘制一个顶点就更新一次属性；将其设置为1，表示每绘制一个实例才更新一次属性数据。这样GPU在绘制同一个小行星的所有顶点时，都会使用同一个 model 矩阵。

    3. 渲染循环提交绘制

    完成VAO的配置后，在主渲染循环中，只需将原本的绘制指令替换为带 Instanced 后缀的函数，并传入实例总数（如 rockAmount）：

    rockShader.use();
rockShader.setMatrix4("view", view);
rockShader.setMatrix4("projection", projection);

for (unsigned int i = 0; i < rockModel.meshes.size(); i++)
{
    glBindVertexArray(rockModel.meshes[i].GetVAO());
    // 提交实例化绘制
    glDrawElementsInstanced(GL_TRIANGLES, rockModel.meshes[i].indices.size(), GL_UNSIGNED_INT, 0, rockAmount);
}

    仅需一次Draw Call，GPU就会利用我们提前放置在显存中的变换矩阵数组，高效地将十万个小行星一次性渲染出来。
